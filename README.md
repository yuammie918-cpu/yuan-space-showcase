# YuanSpace

> 面向中文用户的个人数字策展空间

[访问 YuanSpace](https://yuanspace.net) · [访问个人博客](https://blog.yuanspace.net)

## 项目介绍

YuanSpace 是一个持续维护的个人数字策展空间，用于整理值得长期访问的互联网内容，并呈现个人创作与项目实践。

它不只是一个网址导航，也不追求简单堆叠链接。每项内容都会根据实际用途、信息质量、访问体验和长期价值进行筛选与整理，尽量帮助中文用户更快找到真正有用的产品、网站和独立作品。

## 主要内容

- **AI 产品图鉴**：整理不同方向的 AI 产品，提供基础信息、功能说明、使用入口与编辑评价。
- **实用资源导航**：收录学习、开发、设计、阅读、影音、社区、游戏和效率等方向的优质资源。
- **独立项目推荐**：关注完成度较高、有独特价值的开源项目和独立开发者作品。
- **个人内容创作**：展示文章、学习记录、项目经历与个人博客内容。
- **YuanSpace Cosmos**：通过独立的视觉交互空间呈现站点世界观和个人表达。

## 关于这个仓库

这是 YuanSpace 的**公开展示仓库**，仅包含项目介绍和公开信息。

YuanSpace 的实际源代码、部署配置、内容数据和构建文件保存在私有仓库中，不在这里公开。本仓库不是源码发行包，也不提供本地安装或二次部署方式。

## 技术概览

YuanSpace 由 Next.js、TypeScript 和 Tailwind CSS 构建，主站与个人博客独立运行，并通过自动化流程部署到自有服务器。

这里仅提供技术概览，不包含实现代码或部署凭据。
